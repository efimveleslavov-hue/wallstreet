# wallstreet

## Telegram-MCP setup

Скрипты и инструкция для подключения Telegram к Claude Code (локально, на Mac)
через сервер [`chigwell/telegram-mcp`](https://github.com/chigwell/telegram-mcp):

см. [`telegram-mcp-setup/README.md`](telegram-mcp-setup/README.md).

Быстрый старт:

```bash
bash telegram-mcp-setup/01-install.sh    # установка
# затем получить ключи и сгенерировать строку-сессию (см. README)
bash telegram-mcp-setup/02-register-mcp.sh   # регистрация в Claude
```
