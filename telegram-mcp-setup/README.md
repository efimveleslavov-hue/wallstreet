# Подключение Telegram к Claude Code через MCP (локально, на Mac)

Цель — чтобы **Claude Code на твоём Mac** мог отправлять сообщения от твоего
Telegram-аккаунта через открытый сервер [`chigwell/telegram-mcp`](https://github.com/chigwell/telegram-mcp)
(на базе Telethon).

> ⚠️ Важно про среду. Эти скрипты рассчитаны на запуск **на твоей машине**
> (в обычном терминале / в Claude Code на десктопе). В веб-версии Claude Code
> (claude.ai/code) настройка не сохранится: контейнер одноразовый и удаляется
> после сессии, а MCP-серверы подхватываются только при старте новой сессии.

> 🔐 Про секреты. `TELEGRAM_API_HASH` и строка-сессия — это полный доступ к
> твоему аккаунту. Не выкладывай их в git, не пересылай в чаты. Файл `.env`
> добавлен в `.gitignore`. Строка-сессия хранится только в конфиге Claude на
> твоей машине.

---

## Шаг 1. Установить сервер

В терминале, из корня этого репозитория:

```bash
bash telegram-mcp-setup/01-install.sh
```

Скрипт: проверит `git`/`python3` (при отсутствии поставит через Homebrew),
склонирует репозиторий в `~/telegram-mcp`, создаст `.venv`, выполнит
`pip install -e .` и создаст `~/telegram-mcp/.env` из шаблона.

## Шаг 2. Получить API-ключи (делаешь ты)

1. Зайди на <https://my.telegram.org/apps> под своим номером Telegram.
2. Создай приложение: **App title** любой (например `ags-mcp`), **platform** — Desktop.
3. Скопируй **API_ID** (число) и **API_HASH** (строка).
4. Впиши их в `~/telegram-mcp/.env`:

   ```
   TELEGRAM_API_ID=<твоё число>
   TELEGRAM_API_HASH=<твоя строка>
   ```

## Шаг 3. Сгенерировать строку-сессию (код из Telegram вводишь ты)

Код приходит тебе в Telegram — за тебя его никто не введёт. В той же папке,
с активированным окружением:

```bash
cd ~/telegram-mcp
source .venv/bin/activate
python session_string_generator.py
```

Введёшь: номер телефона (в формате `+7…`), код из Telegram и пароль 2FA
(если он у тебя включён). Скрипт напечатает длинную **строку-сессию** —
скопируй её целиком.

Впиши её в `~/telegram-mcp/.env` в `TELEGRAM_SESSION_STRING=…` (можно в кавычках),
либо будь готов вставить её на следующем шаге по запросу.

> 🍎 macOS + Python с python.org: если увидишь ошибку SSL-сертификата,
> выполни перед запуском:
> `export SSL_CERT_FILE=$(python -m certifi)`

## Шаг 4. Зарегистрировать сервер в Claude

```bash
bash telegram-mcp-setup/02-register-mcp.sh
```

Скрипт возьмёт `API_ID`/`API_HASH` из `.env`, спросит строку-сессию (если её
нет в `.env`) и выполнит `claude mcp add telegram-mcp --scope user …`, затем
покажет `claude mcp list`.

Сервер `telegram-mcp` должен быть **✔ Connected**.

## Шаг 5. Проверка перед рассылкой

MCP-серверы подхватываются при старте — **открой новую сессию Claude Code**,
затем попроси Claude вызвать `mcp__telegram-mcp__get_me` (или `list_chats` с
лимитом 1) и убедись, что это именно твой аккаунт. Только после этого переходи
к рассылке.

---

## Если что-то не так

| Симптом | Что делать |
|---|---|
| `telegram-mcp` не Connected | Проверь путь бинаря `~/telegram-mcp/.venv/bin/telegram-mcp` и что `pip install -e .` прошёл без ошибок. |
| Ошибка кода / «session expired» | Повтори Шаг 3 — сгенерируй строку-сессию заново, потом Шаг 4. |
| SSL-ошибка на macOS | `export SSL_CERT_FILE=$(python -m certifi)` перед запуском. |
| Инструмент не появился в Claude | MCP грузится при старте — перезапусти сессию Claude Code. |

## Ответственность и правила Telegram

Рассылки от личного аккаунта попадают под антиспам-правила Telegram: массовая
отправка незнакомым людям может привести к ограничениям или блокировке номера.
Используй это для переписки со своими контактами/клиентами и соблюдай правила
Telegram.
