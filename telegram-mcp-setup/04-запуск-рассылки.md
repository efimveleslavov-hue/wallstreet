# 04 — Запуск рассылки (промпт для терминального Claude)

Рассылка запускается **в терминальном `claude` на Mac** (там подключён
`telegram-mcp`), а не в Cowork/веб-версии.

## Как запустить

1. В терминале зайди в папку, где лежат файлы `02…` и `03 РАССЫЛКА — кому что слать.md`.
2. Запусти `claude`.
3. Вставь промпт ниже целиком.
4. На запрос разрешения инструментов `telegram-mcp` — разреши (можно «always allow»,
   чтобы не подтверждать на каждом из 21).

## Промпт

```
Разошли напоминания CPT-трейдерам от моего имени через telegram-mcp. Получатели, телефоны/@username и ГОТОВЫЕ тексты — в файле "03 РАССЫЛКА — кому что слать.md" в текущей папке. Прочитай его. Тексты финальные, с подставленными логином/паролем — НЕ меняй их.

Это мои контакты с активными переписками. Действуй строго по одному, по порядку с №1 по №21:

Для каждого получателя:
1) add_contact(phone="+7…", first_name=имя) → возьми числовой id из ответа.
2) send_message(chat_id=<id>, message=<текст из блока этого человека>).
3) Если телефон не находится / пустой — resolve_username("@…") → затем send_message на полученный id. (У Алексея Махно №21 только username — сразу через него.)
4) Пауза 60–90 секунд между людьми.
5) После каждой отправки коротко отметь: кому ушло (✅) или ошибка.

Правила:
- Строго по одному, с паузами. Всего 21 — это ~30–40 минут, не торопись.
- Ничего не придумывай и не дописывай к текстам — шли как есть. Без картинок и файлов, только текст.
- Помеченным "⚠️ отказ" тоже шли (текст тот же, мягкий). Если кто-то ответит негативом — не спорь, поблагодари и заверши.
- Если получатель ОТВЕТИТ — не отвечай за меня. Покажи мне его ответ и жди, что я скажу.
- Если отправка упала (chat_id не найден и т.п.) — не бросай рассылку, пометь "не отправлено, причина …" и иди дальше.

В конце выведи таблицу: получатель · отправлено (✅/✖) · время. Список неотправленных — отдельно.

Начинай с №1.
```

## Примечание

Логика соответствует файлу `02`. Файлы `02`/`03` с получателями и текстами
в репозиторий не коммитятся (личные данные и доступы) — держи их только локально.
